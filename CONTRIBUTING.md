# Contributing to Nebuchadnezzar’s Tongue / WNEP‑Crucible

Thank you for your interest. This project thrives on **falsifiability, transparency, and free expression**.

## How to Contribute

1. **Fork the repository** and create a branch.
2. **Add or improve a tool** – e.g., new prohibition patterns, additional codebooks, better documentation.
3. **Write tests** where applicable (we use `pytest` for Python modules).
4. **Open a pull request** with a clear description of what it does and why.

## Contribution Guidelines

- All code must be **legal** and **non‑malicious**.
- Do not add features that could be used for doxxing, stalking, or harassment.
- Maintain **gilding‑stripping** – avoid introducing evaluative or emotionally charged language.
- Respect the **AGPL license** – any derivative work must also be open source.

## Style

- Python: follow PEP8.
- Documentation: write in clear, neutral English.

## First‑time contributors

Look for issues labelled `good first issue`. We also welcome improvements to the `theory.md` mathematical exposition.

Thank you for defending free speech!
