1. CORE MATHEMATICAL DEFINITION (applies to all evaluations)
============================================================

Let A be a fixed finite set of prohibition patterns (α1, α2, α3, α4, α4b).
Let P be a set of agents.
For each agent p ∈ P:
  - claim(p) ∈ {true, false} (agent asserts adherence to T1796 proxy: e.g., loyalty to own nation's interests)
  - actions(p) ⊆ X, where X is the universe of observable actions expressed via the neutral action schema.

Define matching relation M ⊆ X × A such that (x, α) ∈ M iff the stripped structural pattern of action x instantiates pattern α.

Consistency predicate:
  consistent(p) ≡ ¬( claim(p) ∧ ∃α∈A, ∃x∈actions(p): (x,α)∈M )

Exposure predicate:
  exposed(p) ≡ claim(p) ∧ ( ∪_{x∈actions(p)} { α∈A | (x,α)∈M } ≠ ∅ )

Verdict:
  if claim(p)=false → "no_claim"
  else if exposed(p) → "inconsistent" (with matched patterns)
  else → "consistent"

For the Crucible (US political actors), the verdict strings become:
  "apotheosis_achieved" (consistent)
  "washingtonian_evil" (inconsistent)
  "no_claim"
